# fedacking's square Firefox

Square corners and tab tweaks for Firefox (tested on 157).

## Install

1. In `about:config`, set `toolkit.legacyUserProfileCustomizations.stylesheets` to `true`.
2. Open `about:support`, find **Profile Folder**, click **Open Folder**.
3. Create a `chrome` folder there and copy `userChrome.css` and `userContent.css` into it.
4. Restart Firefox.
